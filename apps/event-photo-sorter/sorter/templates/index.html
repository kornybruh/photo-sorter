How to use Event Photo Sorter
  • The photo on screen is the one you're deciding right now. Click it (or drag it onto a category card) to view full-size / file it.
  • Custom category makes any category you want -- type a name, e.g. "people_1" for a person slot, "atmosphere" for venue/no-people shots, or anything else.
  • Every category becomes a card in the scrollable strip up top: click its thumbnail to file the current photo there too (hover to preview it bigger first). Open opens that folder in Windows Explorer, the pencil renames it, the trash bulk-deletes the whole category (sends every photo in it back to unsorted).
  • The grid icon toggles bulk mode -- select several photos at once and file them together in one click, good for near-identical burst shots.
  • Skip leaves a photo for later; skipped photos come back into rotation once everything else is decided. Undo reverts your last decision.
  • Keyboard: arrow keys move a highlight along the category strip (works in any layout), and Enter files the current photo (or your bulk selection) into whichever category is highlighted.
  • Sync from disk reconciles progress if you deleted photos via Explorer. Clear All wipes every sorted folder + progress for everyone (only the copies -- originals are always safe) -- it asks for confirmation, and only works from the host PC itself, not from other devices on WiFi.
  • Multiple people can sort at once from different devices on the same WiFi -- the host sets "how many people" once, and everyone else who opens the link gets auto-assigned a player number, no picking required. The people icon opens a live view of everyone's progress, updating every 2 seconds.
  • To sort a different event: pick a different folder from Settings -- everything (sorted output, progress) is regenerated fresh inside whichever folder you point it at.
